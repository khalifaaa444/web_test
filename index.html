Usage Guide & Information

RSSI Signal Strength

  • -30 to -50 dBm: Excellent signal
  • -50 to -70 dBm: Good signal
  • -70 to -90 dBm: Weak signal
  • Below -90 dBm: Very weak signal

Browser Compatibility

  • ✅ Chrome 79+ (Desktop/Android)
  • ✅ Edge 79+
  • ✅ Opera 66+
  • ❌ Firefox (Not supported)
  • ❌ Safari (Limited support)

ESP32 Setup

  • Device name should contain "ESP32"
  • Advertising interval: 100-1000ms recommended
  • Include manufacturer data for custom payload
  • Ensure ESP32 is powered and within range

Troubleshooting

  • Enable Chrome flag: chrome://flags/#enable-experimental-web-platform-features
  • Ensure Bluetooth is enabled on your computer
  • Check browser console (F12) for errors
  • ESP32 range: typically 10-30 meters
